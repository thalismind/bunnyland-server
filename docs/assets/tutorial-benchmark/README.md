# Tutorial benchmark map art

These top-down tabletop maps are atmospheric report illustrations. The report's generated
SVG maps remain authoritative for room names, exits, milestone placement, and clue analysis.

The images were generated with the built-in image generation tool using:

- The corresponding generated topology SVG as a composition reference.
- Bunnyland's `banner-main.png`, `logo-sim-life.png`, and `banner-sim-garden.png` as
  character and environmental style references.
- A shared prompt direction: aged-parchment D&D tabletop cartography, strict top-down view,
  ink outlines, watercolor washes, Bunnyland-style white rabbits, no labels, no grid, no
  route arrows, and no watermark.

Asset-specific prompt direction:

- `apple-crossing-tabletop.png`: a rural crossroads with the post hut north, apple hedge
  east, footbridge south, and the courier handoff scene at the center. Pip and Pippa were
  explicitly revised from mice to long-eared Bunnyland rabbits.
- `bell-green-tabletop.png`: all twelve Bell Green locations, with the Post Office, Garden
  Walk, Inn, Market Lane branches, River Footbridge, shrine, and Courier Path.
- `clover-city-tabletop.png`: all twenty Clover City locations arranged around the lobby,
  including the facility branches, apartment wing, street stop, and corner store.

Do not use the raster art to evaluate navigation correctness. Image generation can simplify
or soften exact geometry; use the SVG topology and benchmark evidence for analysis.
